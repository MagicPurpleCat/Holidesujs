## Три направления

### Целостность экономики (сначала)

- Вернуть ставку блэкджека, если рука истекла.
- `UPDATE last_work_at` в одной транзакции с выплатой.
- `/giveaway cancel` и возврат платного входа.

### Мультисервер

- `guild_id` в activity, settings, shop, boosts, verification.
- После рестарта снова подписать тех, кто уже в войсе.
- Ключи shop/rep/антиспама с `guildId`.

### Игрокам видно

- Тикеты и роль сезона внутри `/setup`.
- Кэш аватара, шрифт в репозитории, пол и статус на карточке.
- Анти-AFK по реальной тишине, не по unmute.

## Не стоит трогать

- Музыкальный бот — отдельный продукт, в коде его нет.
- OS-шардинг — уже есть несколько клиентов в процессе, вынос в OS нужен на десятках тысяч участников.
- Полный переход на TypeScript — большой объём при живом ESM-боте, мало пользы сразу.
- Регистрация команд только через `npm run register` — это сознательно, чтобы не ловить rate limit Discord.
