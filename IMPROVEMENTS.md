## Уже исправлено

- Односерверный режим: `utils/singleGuild.js`, выход с чужих гильдий, фильтр событий/интеракций.
- Анти-AFK фарма: `last_voice_reset_time` только при входе/unmute; через 20 мин тишины ставка ×0.1; нужны ≥2 человека (не боты).
- `/setup`: шаги тикетов и роли сезона (+ пропуск); персист визарда в `ephemeral_state`.
- Клановый магазин: проверка `ManageRoles`/иерархии **до** списания банка.
- Достижения: DM/канал при разблокировке; `/достижения поиск:…`.
- Профиль: gender на карточке; статус уже рисовался.
- `/помощь` строится из зарегистрированных команд; текст про один сервер.
- Панель комнаты: сессия в `ephemeral_state` переживает рестарт.

## Очередь (низкий приоритет)

| Приоритет | Что | Почему |
|---|---|---|
| Низкий | Шрифты в `fonts/` | Если нет TTF — canvas падает на системный sans (особенно Linux). |
| Низкий | `guild_id` в legacy-таблицах | Activity/settings всё ещё глобальные — не критично при одном сервере. |
| Низкий | Единый язык slash-имён | Алиасы `help`/`помощь` оставлены сознательно. |

## Не стоит трогать

- Музыкальный бот — отдельный продукт.
- OS-шардинг — рано.
- Полный TypeScript — мало пользы сразу.
- Регистрация команд только через `npm run register`.
