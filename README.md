# Holidesu

Discord-бот для сообщества: экономика ⚡HLD, уровни, магазин ролей, казино, кланы, приватные комнаты, модерация и верификация.

**Стек:** Node.js 22.5+ · discord.js v14 · SQLite (`node:sqlite`) · dotenv · canvas (опционально)

---

## Требования

- [Node.js](https://nodejs.org/) **22.5 или новее** (нужен встроенный `node:sqlite`)
- npm 9+
- приложение бота в [Discord Developer Portal](https://discord.com/developers/applications)

Включи у бота Privileged Gateway Intents: **Server Members**, **Message Content**, **Presence** (если используешь реакции/репутацию с реакциями).

## Быстрый старт

### 1. Зависимости

```bash
npm install
```

При `npm start` бот сам проверяет пакеты. Если нет `discord.js` или `dotenv` — ставит их. Если нет `canvas` — пробует поставить; если не получилось, профиль показывается текстом.

### 2. Файл `.env`

Скопируй `.env.example` в `.env` и заполни:

```env
DISCORD_TOKEN=
CLIENT_ID=
GUILD_ID=
FARM_RATE=10
OWNER_ID=
TRIGGER_CHANNEL_ID=
VOICE_CATEGORY_ID=
VERIFIED_ROLE_ID=
EXTRA_VERIFY_ROLES=
```

| Переменная | Зачем |
|---|---|
| `DISCORD_TOKEN` | токен бота (Portal → Bot → Reset Token) |
| `CLIENT_ID` | Application ID (Portal → General Information) |
| `GUILD_ID` | ID сервера: команды появляются сразу, без ожидания глобальной регистрации |
| `FARM_RATE` | ⚡HLD за минуту в голосовом канале (по умолчанию 10) |
| `OWNER_ID` и каналы/роли ниже | запасной вариант, если ещё не запускали `/setup` |

Каналы, роли админов и welcome задаются командой **`/setup`** — она важнее значений из `.env`.

Если `.env` нет, при старте он создаётся из `.env.example`.

### 3. Запуск

```bash
npm start
```

или `node start.js`.

Slash-команды при обычном `npm start` **не** регистрируются. Чтобы опубликовать их:

```bash
npm run register
```

или `node start.js --register` (сначала регистрация, потом запуск бота).

После первого запуска на сервере выполни **`/setup`**: владелец, админ-роли, каналы логов, команд, модерации, голосовой панели, триггер Join-to-Create, категория комнат, канал приветствий. Роли уровней и доп. роли верификации тоже задаются в `/setup`, а не зашиты в код.

## Команды

### Для всех

| Команда | Что делает |
|---|---|
| `/помощь`, `/help` | список команд |
| `/баланс` | баланс ⚡HLD |

| `/profile` | профиль (картинка или текст) |

| `/топ` | топ-10 по категориям |
| `/shop` | магазин ролей и бустов |
| `/role` | личная роль: создать, управление, инвентарь, скрыть |
| `/casino daily` | ежедневный бонус 200 ⚡HLD |
| `/casino slot` | слоты (ставка 10–10 000) |
| `/casino coinflip` | орёл/решка (ставка 10–10 000) |
| `/work` | подработка раз в час |
| `/квесты` | ежедневные задания |
| `/сезон` | недельный рейтинг; админ может задать роль 1 места |
| `/cosmetics` | рамки и фоны профиля |
| `/casino blackjack` | блэкджек |
| `/clan` | кланы + `/clan shop` |
| `/семья` | общий счёт супругов |
| `/реп`, `/rep` | репутация (не себе, кулдаун 1 час, до 20 в сутки) |
| `/marry` / `/divorce` | брак и развод |
| `/room-settings` | панель своей голосовой комнаты |
| `/server-stats` | статистика сервера (картинка) |
| `/verify` | верификация |
| `/settings` | настройки профиля |
| `/meme-gen` | случайный мем или фраза |

### Для модерации и админов

| Команда | Кто | Что делает |
|---|---|---|
| `/mod` | модератор+ | warn, mute, unmute, kick, ban, unban, список варнов |
| `/history` | модератор+ | история наказаний |
| `/логи` | админ | каналы и уровень логов |
| `/панель` | админ | экономика, права, верификация, модерация |
| `/фичи` | админ | включить/выключить модули бота |
| `/setup` | админ | мастер настройки сервера |
| `/giveaway start` | модератор+ | розыгрыш (бесплатно или за ⚡HLD) |
| `/ticket setup` | админ | панель тикетов |
| `/ticket close` | автор/модератор | закрыть тикет |

Создание роли в `/shop` и `/role` стоит **5000 ⚡HLD**. Создание клана — **1000 ⚡HLD**.

## Возможности

- **Экономика.** Стартовый капитал 100 ⚡HLD на каждом сервере. Фарм в войсе, `/work`, `/pay`, магазин, квесты.
- **Сезон.** Недельный топ по XP/сообщениям/голосу. Топ-3 получают 1500/1000/500 ⚡HLD.
- **Серверная статистика.** `/server-stats` — топ-10 по метрикам и график роста среднего общего рейтинга.
- **Казино.** Слоты, монетка, блэкджек. Максимальная ставка 10 000.
- **Кланы.** Банк, войны со ставкой, магазин: буст фарма, тег в профиле, роль.
- **Брак.** Семейный счёт `/семья`, +15% фарма в одном войсе.
- **Тикеты и розыгрыши.** `/ticket setup`, `/giveaway start`.
- **Профиль.** Достижения и косметика (`/cosmetics`).
- **Комнаты.** Заход в канал-триггер создаёт приватную комнату, панель у владельца.
- **Стат-голосовые каналы.** В `/setup` можно создать каналы “Люди: X” и “Боты: Y” (видны всем, подключаться нельзя).
- **Приветствие.** RPG-embed и 100 ⚡HLD новым участникам (канал из `/setup`).
- **Модерация.** Иерархия ролей: нельзя наказать вышестоящего. Мут до 28 дней. `/mod unmute` и `/mod unban`.
- **Права.** Owner (3) не может выдать уровень Owner другому. Админ выдаёт только модератора. Модули сервера — `/фичи`.

## Автоматическая публикация changelog (GitHub Actions)

Если в репозитории настроен secret `DISCORD_RELEASE_WEBHOOK_URL`, то при `push` в `main` GitHub Actions отправляет секцию `## [Unreleased]` из `CHANGELOG.md` в Discord (в канал, куда ведёт webhook).

## Структура проекта

```

database.js              SQLite, экономика, XP, наказания
register-commands.js     публикация slash-команд
handlers/                интеракции и события сервера
commands/                slash-команды
modules/                 голос, верификация, логи, welcome, бэкап БД
utils/                   конфиг сервера, права, лог
src/                     менеджер шардов
photo/                   фон профиля и картинка верификации
data/                    база holidesu.db (создаётся сама, в git не входит)
tests/                   unit-тесты
```

## База данных

Файл: `data/holidesu.db`. Каталог создаётся при первом запуске.

Копии БД пишутся в `data/backups/` (хранятся 7 файлов).

Для тестов путь можно задать переменной `HOLIDESU_DB_PATH`.

## Безопасность

- SQL только через подготовленные запросы
- kick / ban / mute с проверкой иерархии ролей
- `/history` только для модераторов
- `.env` не коммитится
