# Changelog

Все заметные изменения Holidesu. Формат близок к [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Unreleased] — 2026-08-19 (сессия ~5 ч, ~17:00–22:00 МСК)

Коммиты: `fe420de` (аналитика и надёжность), `3bf041a` (welcome, роли, достижения, старт).

### Добавлено

#### Приветствие новичков
- Canvas-баннер при входе на сервер (`modules/canvas-welcome.js`): аватар, ник, счётчик участников, блок **«Стартовый баланс»** вместо «БОТ».
- Приветствие **только в канал** — без DM. Сообщение: пинг участника + картинка + кнопка «Перейти в основной канал» (`1528102721679265973`). Текстовый embed убран.
- Админ-превью: `/welcome-preview`.

#### Панель самовыбираемых ролей
- Команда `/self-roles`:
  - `setup` — публикация панели в канале `#роли` (`1528854421797208134`);
  - `create` — создать роли на сервере без публикации;
  - `status` — проверить привязки ролей.
- Canvas-баннер панели с карточками ролей и пояснениями (`modules/canvas-self-roles-panel.js`).
- Группа **🔔 Уведомления** — три ping-роли: **📢 Анонсы**, **🎉 События**, **🤖 Holidesu** (можно комбинировать).
- Автосинхронизация Discord-ролей при старте бота (`initSelfRolesForGuild` в `bot.js`).
- Select-меню под панелью; выдача/снятие ролей через `handlers/interactions.js`.
- Краткий текст embed под картинкой (без дублирования длинных описаний с баннера).

#### Достижения
- Команда `/достижения` — список, фильтры, пагинация.
- Каталог достижений (`modules/achievementsCatalog.js`) с прогрессом в профиле и экономике.

#### Аналитика сервера (коммит `fe420de`)
- Slash `/server-stats` с Canvas-карточкой и графиком роста (`modules/canvas-server-stats.js`).
- Голосовые stat-каналы через `/setup` (`modules/serverVoiceStats.js`).
- Ежедневные снимки активности сервера (`modules/serverStatsDaily.js`).

#### Запуск и инфраструктура
- Автопроверка версии Node.js при старте (`utils/ensureNode.js`): если ниже `>=22.5.0` из `package.json`, пробует обновить через **fnm → nvm → winget → choco → brew** и перезапускает `start.js`.
- GitHub Action — публикация `CHANGELOG.md` в Discord при пушах.

### Изменено

#### Профиль и экономика
- Расширена Canvas-карточка профиля 1920×1080: больше полей, аккуратнее layout (`modules/canvas-profile-minimal.js`).
- `/profile` — достижения, прогресс, доп. статистика.
- `/top` — обновлённые рейтинги и отображение.
- `/shop`, `/work`, `/rank` — доработки UX и расчётов.
- `/casino blackjack` — улучшения сессий; `/giveaway` — доработка платного входа и отмены.

#### Отношения и брак
- Переработаны `/marry` и модуль `modules/relationships.js`: заявки, развод, семейный счёт, стабильнее транзакции.

#### Рейтинг и прогресс
- Общий score учитывает минуты в голосе (`modules/score.js`).
- Прогресс XP/уровней и level-up уведомления (`modules/progress.js`).

#### Приветствие и события
- `modules/welcomeNPC.js` упрощён под канальный формат (без RPG-embed в DM).
- `handlers/guildEvents.js` — welcome при `guildMemberAdd`, восстановление voice-фарма после рестарта.

#### Прочее
- `/help` — новые команды в справке.
- `/rep`, антиспам — ключи с `guildId` (изоляция по серверу).
- `README.md`, `IMPROVEMENTS.md` — актуализированы под текущее состояние.

### Исправлено

- **Join-to-Create:** комната создаётся при переходе в канал-триггер; если старая запись в БД мёртвая — чистится и создаётся новая.
- **Экономика:** атомарный кулдаун `/work`; возврат ставки блэкджека по TTL; `/giveaway cancel` возвращает платный вход.
- **Self-roles:** `COMPONENT_INVALID_EMOJI` в select-меню (корректный split эмодзи); дублирующий export `initSelfRolesForGuild`.
- **Надёжность:** единый fallback для ошибок interaction + guild-логирование (`utils/errorHandling.js`).
- Тесты экономики расширены — **25/25** (`tests/economy.test.js`).

### Для разработчиков

- Новые slash-команды: `npm run register` или `node start.js --register`.
- После деплоя **перезапусти бота** — подхватятся welcome, self-roles sync и stat-каналы.
- Панель ролей обновить: `/self-roles setup`.
- Превью welcome: `/welcome-preview`.
- Node.js **22.5+** обязателен (`node:sqlite`); при старте проверяется автоматически.

  - ➕ слот · ➖ слот · 🔒 замок · ✏️ имя · 👥 лимит
